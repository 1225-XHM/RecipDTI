# RecipDTI

RecipDTI is a deep learning framework for drug-target interaction (DTI) prediction. It models reciprocal affinity between molecular fragments and protein residues, and then performs selective feature fusion for interaction classification.

## Environment Setup

### Requirements

- RDKit 2025.9.3
- Python 3.9
- PyTorch 2.1.1
- CUDA 12.1
